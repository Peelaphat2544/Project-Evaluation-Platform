# 🎓 ระบบประเมินผลงานโครงงานนวัตกรรมและเทคโนโลยี (Project Evaluation Platform)
### รายวิชา ออกแบบและวิทยาการคำนวณ 4 (ว30113)

ระบบประเมินผลงานโครงงานแบบ Fullstack ครบวงจร พัฒนาขึ้นเพื่อรองรับการส่งผลงาน การจัดเก็บเอกสารและสื่อนำเสนอตรงเข้าสู่ **Google Drive** พร้อมระบบประเมินผลตามเกณฑ์รูบริกมาตรฐาน 20 คะแนน (Rubric Scoring System) และระบบแสดงผลคะแนนแบบ Real-time

---

## 🌟 ฟังก์ชันและจุดเด่นของระบบ (Key Features)

### 1. 📤 ระบบส่งผลงานโครงงาน (Student Submission)
- **ฟอร์มส่งข้อมูลมาตรฐาน**: รองรับชื่อโครงงาน (ไทย/อังกฤษ), คำอธิบาย, ลิงก์สาธิต (Demo URL), ลิงก์ซอร์สโค้ด (GitHub)
- **ระบบสมาชิกในกลุ่ม**: ระบุชื่อ-สกุล, รหัสนักเรียน, ชั้นเรียน, เลขที่, บทบาทหน้าที่ พร้อมรูปประจำตัวสมาชิกแต่ละคน
- **ระบบรหัสผ่าน Passcode 4 หลัก**: ระบบจัดสรรรหัสผ่านเฉพาะกลุ่ม เพื่อให้นักเรียนกลับมาแก้ไขข้อมูลผลงานตนเองได้
- **Multi-Step Animated Process Bar**: แสดงความคืบหน้าระหว่างอัปโหลด (0% - 100%) พร้อม Checklist ตรวจสอบแต่ละขั้นตอนแบบ Real-time

### 2. 📁 การจัดเก็บไฟล์อัตโนมัติบน Google Drive (Auto Organization)
ระบบจะทำการแยกโฟลเดอร์ย่อยและจัดเก็บไฟล์เข้า Google Drive ให้อัตโนมัติ:
1. `📁 เล่มรายงานโครงงาน` ➔ `เล่มรายงาน_{ชื่อโครงงาน}_{วันที่และเวลาส่ง}.pdf`
2. `📁 สื่อนำเสนอโครงงาน` ➔ `สื่อนำเสนอ_{ชื่อโครงงาน}_{วันที่และเวลาส่ง}.pptx`
3. `📁 รูปภาพสมาชิกและโครงงาน` ➔ `รูปประจำตัว_{ชื่อโครงงาน}_{ชื่อสมาชิก}_{รหัสนักเรียน}.jpg`
- **ระบบลบไฟล์อัตโนมัติ**: เมื่อผู้ดูแลระบบลบโครงงาน ไฟล์ทั้งหมดที่ผูกกับโครงงานนั้นบน Google Drive จะถูกลบออกให้โดยอัตโนมัติ

### 3. 📝 ระบบประเมินผลสำหรับครูผู้สอน (Rubric Evaluation System)
- **เกณฑ์การประเมินรูบริก 20 คะแนน (4 ด้าน)**:
  - 🔍 **ด้านที่ 1: การกำหนดปัญหาและการวิเคราะห์ (5 คะแนน)**
  - 💡 **ด้านที่ 2: การออกแบบเชิงวิศวกรรมและแนวคิดนวัตกรรม (5 คะแนน)**
  - 🛠️ **ด้านที่ 3: การพัฒนาและประสิทธิภาพการทำงาน (5 คะแนน)**
  - 📢 **ด้านที่ 4: การสื่อสาร การนำเสนอ และเอกสารรายงาน (5 คะแนน)**
- **คะแนนพิเศษ (Bonus Score)**: ให้คะแนนพิเศษเพิ่มเติมได้ พร้อมช่องบันทึกข้อเสนอแนะเชิงสร้างสรรค์
- **คำนวณเกรดอัตโนมัติ**: A (18-20), B+ (16-17.5), B (14-15.5), C (10-13.5), F (<10)
- **ส่งออกข้อมูล (Export)**: รองรับการส่งออกข้อมูลเป็น **Excel (CSV)**, **PDF สรุปผลการประเมิน**, และ **Print Report**

### 4. 🏆 กระดานสรุปผลคะแนน (Leaderboard / Scoreboard)
- **แท่นรับรางวัล Top 3 Podium**: แสดงผลงาน 3 อันดับแรกอย่างสมเกียรติ
- **ตัวกรองและการค้นหา**: ค้นหาตามชื่อโครงงาน, ห้องเรียน, ประเภทผลงาน, และเรียงลำดับคะแนน
- **ระบบเปิด/ปิดการแสดงผลคะแนน**: ครูสามารถเปิดหรือปิดการแสดงผลคะแนนได้ตามต้องการ

### 5. 📱 รองรับทุกอุปกรณ์ (Mobile & Responsive Ready)
- ใช้งานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน

---

## 🛠️ เทคโนโลยีที่ใช้ในการพัฒนา (Tech Stack)

- **Frontend**: Vanilla HTML5, Modern CSS3 (CSS Variables, Flexbox, CSS Grid), Vanilla JavaScript (ES6+ Modules)
- **Backend**: Node.js, Express.js, Multer (Multipart Form Data Stream)
- **Cloud & Database**:
  - **Google Drive API v3**: จัดเก็บไฟล์รายงาน สไลด์ และรูปภาพ
  - **Firebase Firestore**: ฐานข้อมูลแบบ Real-time เก็บข้อมูลโครงงานและการประเมิน
- **Visualization**: Chart.js (กราฟเรดาร์และสถิติคะแนน), FontAwesome 6

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. ตั้งค่าไฟล์ Environment (.env)
สร้างไฟล์ `.env` หรือคัดลอกมาจาก `.env.example`:
```env
PORT=3000
GOOGLE_DRIVE_FOLDER_ID=your_google_drive_folder_id_here
```

### 3. เริ่มต้นเซิร์ฟเวอร์
```bash
npm start
```
หรือ
```bash
node server.js
```

### 4. เข้าสู่ระบบผ่านเบราว์เซอร์
เปิดเบราว์เซอร์แล้วไปที่: **`http://localhost:3000`**
